# T-033 趣味性与平衡性改造：「武器各有用武之地」· 变更说明

> 需求：可玩性低——「只用一把武器就能直接过关」（试玩实测大刀站桩通关）。
> 用户拍板：渐进解锁（修订 2026-08-30「三把随时切」设计）+ 怪物克制/换武连携/机枪过热三管齐下 + 一期全量。
> 画布方案 C 未触碰（canvas-lock 6/6）；全部数值进配置 + validator；未新增 npm 依赖。

## 一、根因（实測数值）

- 改造前单目标 DPS：机关枪 100（射程 620 全场最高 + 穿透）、大刀 81（AoE 130° + 强击退 300）、霰弹 65。
- 所有普通小怪 100% 同质（同血量/速度/近战追击），切武器零成本零收益，自动瞄准 460 全角——**无脑站桩是最优解**。
- 大刀实为群怪之王（AoE 命中 N 只即 N 倍有效 DPS + 击退控场），比理论单体 DPS 更强——与试玩反馈一致。

## 二、六把武器（机制各不相同，按上手难度渐进解锁）

| # | 武器 | 机制 | 解锁 |
|---|---|---|---|
| 1 | 大刀 | 近战 AoE 扇形 + 强击退（初始武器，最简单） | 初始 |
| 2 | 机关枪 | 持续扫射 + **过热**（18 发强制冷却 2s） | 通关 L2 且正确率 ≥60% |
| 3 | 霰弹枪 | 近距 5 弹散布爆发 + 击退 | 通关 L4 且正确率 ≥60% |
| 4 | 公式飞盘 | **回旋镖**：飞出 ×1.6 处折返再飞回，**双程都可命中**（折返时清空命中表） | 通关 L7 且正确率 ≥60% |
| 5 | 酸液试管 | **抛掷落地区**：不与怪碰撞，射程尽头炸出 2.4s 腐蚀水洼（区域压制） | 通关 L10 且正确率 ≥60% |
| 6 | 单词追踪弹 | **自动追踪**最近小怪（中途中转向），永不落空 | 通关 L13 且正确率 ≥60% |

- 解锁绑定**答题**（通关 + 正确率 ≥60%）：武器成长本身就是核心绑定的延伸。
- 老玩家存档自动迁移：按已解锁关卡推导补全（L14 老档 → 全链 6 把，实测 ✓）。
- 数值再平衡（新 DPS）：大刀 65 / 机关枪 75 / 霰弹 109（贴脸）/ 飞盘 58×多目标 / 追踪 47（永不空）——**没有一把在所有场景最优**。

## 三、四种怪物变体（克制矩阵，fromLevel 逐步进场）

| 变体 | 特征 | 克制关系 |
|---|---|---|
| 铁锅头（L4+，无厘头担当） | 头顶铁锅，血 ×1.5 | **吃刀 ×1.6、吃子弹 ×0.5**（实测：刀 46.8 vs 枪 5.85，8 倍差） |
| 冲刺怪（L3+） | 血 ×0.6、周期性 ×3.2 猛冲 | 散布/击退好打，大刀难摸 |
| 扔书怪（L5+） | 保持 300 距离投掷腐蚀书（落地伤害区，复用 DoomZone） | 远程武器对狙，大刀够不着 |
| 分裂怪（L6+） | 死后一分为二（小体快怪 noSplit 防无限分裂） | 散布清群吃香 |

- `taken` 伤害倍率表按**攻击形态**（melee/ranged_bolt/ranged_spread/ranged_boomerang/lobbed/ranged_homing）配置；CombatSystem `damageFor` per-monster 结算，**飘字显示克制后的真实伤害**——玩家能看见「打铁锅当啷一声只掉 3 点」。
- 变体加权随机 + fromLevel 门槛（L1-2 纯基础怪教学期）；贴图 4 张程序化变体（铁锅/眼镜书/流线楔形/裂纹），零素材红线内。
- DoomZoneSystem 从 Boss 关专属改为**常驻**（扔书怪/酸液共用）。

## 四、换武连携（软激励）

击杀后 1.5s 内切武器 → 下一击伤害 ×1.25 + 飘字「连携！」——正反馈搓招，不惩罚单武器。

## 七、边界与调参

1. 解锁链 `gameSettings.weaponUnlockSettings`、变体表 `grassCuttingConfig.monsterVariants`、
   过热 `weaponConfig.smg.overheat`、连携 `weaponConfig.switchBonus` 全部即改即生效。
2. 大刀回调幅度（30/0.46）保证了它仍是最好的**入门**武器；若试玩后仍偏强，先降
   `sectorAngle` 120→105（AoE 覆盖），别动伤害（会伤新手手感）。
