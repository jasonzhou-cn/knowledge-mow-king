# T-031 界面文字重叠与答案显示不全修复 · 变更说明

> 用户试玩反馈：① 界面上有些文字互相重叠；② 部分答案显示不全。
> 画布方案 C 未触碰；`verify:canvas-lock` 6/6 复跑通过。

## 一、根因与修复

### 1. 答案显示不全（根因 + 表现两层）

- **根因（真 bug）**：Phaser 的 wordWrap 默认按**空格**断行——中文答案与长英文短语
  根本不会换行，超长就直接溢出卡片被裁掉。修复：新增 `src/ui/FitText.ts`，
  统一强制 `useAdvancedWrap: true`（按字符断行，CJK 正确换行）。
- **表现**：选项字号写死 24px、不随画布缩放。修复：三个选择组件
  （CursorSelector / ArrowSelector / AnswerTrack）统一改用 `createFittedText`——
  基准字号 = 卡片高度 × 0.34（随 vpScale 缩放），换行后高度仍超出卡片则逐级缩字
  （下限 13px），**任何长度的答案都完整落在卡片内**。
- **题干同款处理**：`QuestionScene` 题干改用 `refitText`（超长缩字，下限 18px）+
  advanced wrap；解析文案同样开 advanced wrap。
- **卡片加大（充分利用宽画布）**：`questionConfig.answerSettings`
  optionCardWidth 150→**190**、optionCardHeight 68→**92**（判定区/轨道同步放大：
  cursorHitZone 140×64、selectionZone 320×130、track 半径 260/150、跨度 1100）。
  2340×1080 下选项卡从 253×115 提升到 321×155，基准字号 24→52px。

### 2. 文字重叠（两处，均已消除）

- **主菜单**：「成就 · 图鉴」按钮原先放在开始按钮下方 34s 处，正好压住两行操作说明。
  修复：按钮移到与「开始答题」**同一行**的左侧（achX = 开始按钮左缘 - 96s，垂直居中对齐）。
- **错题弹幕**：原先在活动带内**随机**取 y，两条弹幕可能贴在同一高度叠字。
  修复：`WrongDanmakuSystem` 改**车道制**——活动带按字号×1.8 切分成车道，
  同一条车道同时只允许一条弹幕（弹幕同速永不相撞），车道全满则本次跳过稍后重试。
