# T-030 美术升级：粗线条卡通 + 色彩鲜艳 + 无厘头 · 变更说明

> 需求：提升美工水平——粗线条卡通造型、色彩鲜艳的配搭、无厘头形象。
> 实现路线：**保持「零外部素材」红线**，用程序化 Graphics 贴图烘焙实现卡通风格
> （当前环境无 AI 生图能力，且程序化路线与项目的白灰度贴图 + 运行期 tint 架构完全兼容）。
> 画布方案 C 未触碰；`verify:canvas-lock` 6/6 复跑通过；未新增 npm 依赖。

## 一、卡通风格的技术底座：Palette.art 墨线体系

- 新增 `Palette.art`：`ink`（主墨线）/ `inkSoft`（次级缝线）/ `shadeGray`（暗部灰度）。
- **原理**：全部贴图是白色灰度图 + 运行期乘法 tint——深色像素与任意 tint 相乘仍近似墨色，
  因此粗描边 / 卡通表情 / 赛璐璐阴影直接烘进贴图，全局换色（tint）不受任何影响。
- 这属于 PROGRESS-REVIEW 已判定的「BootScene 贴图烘焙几何」合理例外，不涉配置。

## 三、无厘头形象清单

- **玩家 → 热血小勇士**（64×64 高清重绘）：墨线粗描边圆身 + 头带与两条乱飞的飘带 +
  斗鸡眼大眼（瞳孔齐刷刷望向鼻尖）+ 一高一低怒眉 + 呐喊嘴 + 腮红；脸随朝向旋转（打谁看谁）。
- **小怪 → 呆萌草团怪**（48×48）：钝刺团子 + **一大一小不对称呆眼** + 龅牙两颗 + **头顶发芽两片叶**
  + 「？」眉；底部赛璐璐暗部。
- **主菜单**：右上角**戴墨镜的太阳**（自带墨镜 + 坏笑，没通知任何人）+ 两白一粉糖果云 +

- **五个 Boss 底型**：统一墨色粗描边 + 底部赛璐璐暗部（BossVisual 的表情/配件照常叠加运行期绘制）。

- **战场装饰**：草丛逐株墨线描边；学科装饰（树叶/锥形瓶/几何点）统一墨线粗描边。

## 四、顺手修掉的存量真 bug

`MonsterSpawner.spawnOne` 的 `refreshTint()` 在 `hp/maxHp` 赋值**之前**调用——按池默认值
0/1 计算，所有刚出生的小怪都被当成「残血」染成 75% 精英橙（实测 tint #dfb841）。
这正是开发笔记里「怪物非单色、纯绿检测抓不到满血怪」谜团的真正答案。修复后满血怪
恢复设计意图的鲜绿（实测 #7df04e），受伤时才按血量渐变到橙。

## 六、边界与建议

1. 玩家贴图分辨率 48→64、小怪 36→48：displaySize 由运行时 radius 决定，不影响判定几何。
2. 答题界面（question）本次未动——卡片/判定框是公平性敏感区，保持原样。
3. 云朵/太阳为低透明度氛围元素，若真机上观感过淡/过浓，调整 MenuScene.drawBackdrop 内 alpha 即可。
4. 真机复核建议关注：小怪 48px 纹理缩小到 28px 显示后表情可读性（如偏糊，可把 polishSettings
   的 themeDeco 不动、仅调 monsterRadius）。
