## 二、潜在优化点（技术债 / 体验打磨）

### 代码质量

| 问题 | 现状 | 建议 |
|------|------|------|
| 单元测试覆盖率 | 几乎 0（仅有 smoke-combat.ts 一个） | 加 vitest + 覆盖 resolve.ts / safe area 计算 / cursor selector 判定逻辑 |
| 类型安全 | 部分 any（如 QuestionBank 类型） | 严格收紧，禁用 as any |
| 错误处理 | 异常走 fatal-error，运行时无降级 | 加 try-catch + 友好提示 |
| 日志系统 | 仅 console.log | 加简单 logger 模块（开发/生产分级） |
| 国际化 | 全部硬编码中文 | i18n 模块，支持中英双语 |

### 性能优化

| 项目 | 现状 | 目标 |
|------|------|------|
| 怪物渲染 | Graphics + Image 混合 | 全部用程序生成纹理 + 顶点缓冲 |
| 特效粒子 | 已用 Phaser particle 系统 | 加对象池避免 GC |
| 怪物生成 | 持续 60s 一直生成 | 加难度档位（5 档对应呼吸关） |
| 内存 | 每场景独立重建 | 跨场景对象池 |

### 体验打磨

| 项目 | 现状 | 建议 |
|------|------|------|
| **屏幕反馈** | 无屏幕震动 | 答对/答错/连对触发差异化震动 |
| 音效差异化 | 6 个音效混用 | 答对/答错/连对/升级各自专属音效 |
| 引导动画 | 无 | 第一次玩 cursor 模式显示 5 秒 "▼ 等待游标停在正确选项" |
| 死亡动画 | 0 帧 | 玩家 HP 归 0 时有 1 秒慢动作 |
| 答题时间紧迫感 | 进度条 | 时间剩 3 秒时进度条变红 + 屏幕轻微震动 |

## 三、关键风险与缓解

| 风险 | 缓解 |
|------|------|
| **生产 HTTPS 部署失败** | 先在你 Windows 本机部署测试（生产等价环境），验证全流程后上阿里云 |
| **CDP 模拟与真机差异** | 真机测试不可省略——你手机 5180/5181 两个端口都要试 |
| **题目对孩子太难/太简单** | A/B 测试：cursorCycleDuration 1.5s vs 2.5s，选孩子接受度高的 |
| **儿童隐私合规** | 收集答题数据前需家长同意（已有 GDD 提及但未实现） |
| **关卡难度曲线** | 实测调整，初期让关卡偏易，建立信心 |
