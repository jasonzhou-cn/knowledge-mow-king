# 场景主题视觉规格（T-023，960 × 640）

> 作者：art-director ｜ 版本：v1.0 ｜ 适用：MVP 全部 20 关 + Boss 关
> 设计分辨率：**960 × 640**（与 `src/main.ts` GAME_WIDTH/GAME_HEIGHT 一致，Scale.FIT）
> 复用色板：完全沿用 `src/ui/Palette.ts` 与 `design/art/visual-spec-mvp.md` §2.1 配色
> 风格基线：**沙雕恶搞**（学渣逆袭 / 内卷 / 躺平 / 考神梗 / 表情包），对应玩家 9–18 岁中国学生
> 工程定位：**纯规格文档**，不下载任何素材、不修改任何 .ts / .json 代码

---

## 0. 全局约定

### 0.1 场景主题与学科的对应关系

| 主题 key | 学科 | 主题色（来自 `subjectConfig.json`） | 适用关卡 |
|---|---|---|---|
| `math` | 数学 | `#3D7EA6`（themeColor）+ `#7FD8FF`（accentColor） | L1–L8 |
| `english` | 英语 | `#7A5EA8`（themeColor）+ `#C8A8FF`（accentColor） | L9–L14 |
| `science` | 科学 | `#2F8F6F`（themeColor）+ `#8AFFD0`（accentColor） | L15–L20 |
| `final` | 终极 | 综合 3 学科主题色 + 黑紫渐变 | L20 终极 Boss 关（`L20「元素火山」` 的最终阶段） |

> **重要**：L20 同时是「科学实验室」主题的最后一关 + 「终极（考神祭坛）」主题的承载关。`levelConfig.json` 的 `L20.subject == "science"`，但 Boss「考神」召唤时**切换**到 `final` 主题。具体切换时机见 §4。

### 0.2 场景主题的实现位置

| 元素 | 实现位置 | 复用现有组件 |
|---|---|---|
| 背景底色 | `GrassCuttingScene` 的 `BG_ARENA` 填充 | `visual-spec-mvp.md` §2.1 的 `BG_ARENA` `#111A2E`（**主题色不替换底色**，仅作装饰强调色） |
| 地面棋盘 | `tex_ground_tile` tileSprite | 现有 `visual-spec-mvp.md` §3.2 棋盘 `64 × 64` |
| 主题装饰（草 / 树叶 / 试管 / 符文） | **新增**（在 `BG_ARENA` 之上、地面之下） | T-024 范围 |
| 主题专属 BOSS 配件 | 详见 `boss-visual-spec.md` §1 | 已对齐 |

### 0.3 视觉实现红线

| 红线 | 落实方式 |
|---|---|
| **零素材** | 所有场景装饰均由 `Phaser.GameObjects.Graphics` 程序化绘制后 `generateTexture()` 生成 |
| **不影响性能** | 场景装饰**纯静态**绘制（不参与碰撞、不参与检测），最多 `20` 个同屏（已用对象池约束） |
| **不破坏答题公平** | 场景主题**仅在割草场景**（`GrassCuttingScene`）生效，答题场景始终保持 `BG_MAIN` `#16203A` 主题 |
| **不影响关卡过渡** | 场景主题**不参与关卡切换动效**（§4.12 遮罩动画），仅在 `GrassCuttingScene` 内显示 |

## 1. math（数学草原，L1–L8）

### 1.1 主题氛围

> **关键词**：几何草原，符号飘浮，「学神下凡也要算」。
> **目标玩家**：9–12 岁初学者，第一印象应该是「清爽、温和、不吓人」。
> **色彩温度**：冷蓝 + 暖橙反差（草地为暖橙、数学符号为冷蓝）。

### 1.2 背景色与地面

| 项 | 值 | 说明 |
|---|---|---|
| **背景底色** | `Palette.background.base` `#12263A`（**不替换** `BG_ARENA #111A2E`，仅作装饰强调色） | 沿用 `Palette.ts` |
| **地面棋盘主色** | `Palette.background.base` `#12263A` + `#16351F`（`grassField`）交错 | 沿用 `visual-spec-mvp.md` §3.2 棋盘 |
| **地面棋盘对比度** | `≈ 1.15 : 1`（沿用视觉规格） | 极弱，仅提供运动参照 |

### 1.3 草/装饰规格

> **核心思路**：圆圈小草 + 公式符号（数学感）。
> **数量上限**：同屏 `20` 个装饰对象池（`groundDecoPoolSize = 20`）。

| 装饰元素 | 形态 | 数量 | 位置分布 | 视觉 |
|---|---|---|---|---|
| **圆圈小草** | 实心圆 `radius 4`，填充 `Palette.accent.gold` `#FFCC4D` | **10 个** | 战场区 4 边各 2–3 个，**不挡玩家出生点 `(480, 320)`** `radius 80` 内不出现 | 静态，无 tween |
| **公式符号** | `Phaser.GameObjects.Text`，从 `['π × 7', '∑', '∞', '√', '≠', '≈', 'x²', '+', '−']` 随机选 | **10 个** | 圆圈小草之间穿插，**垂直均匀分布** | `FS_HUD 24`（等宽字体），色 `Palette.text.secondary` `#A8C2D6`，`alpha 0.5`，**水平漂浮 ±8px / 4000ms**（与风感对应） |

### 1.4 装饰 spawn 规则

| 项 | 值 |
|---|---|
| 生成时机 | `GrassCuttingScene.create()` 时一次性生成 20 个装饰对象（10 圆 + 10 符号），从对象池取 |
| 位置分布算法 | 用 `Phaser.Math.Between(40, GAME_WIDTH - 40)` 和 `Phaser.Math.Between(64, GAME_HEIGHT - 70)`（避开 HUD 与底部武器栏），**避开玩家出生点**（距离 < `80` 重抽） |
| 重新分布 | 整关**不重新分布**（避免视觉跳跃） |

### 1.5 适合关卡

| 关卡 | 名称 | 主题强调 |
|---|---|---|
| L1 | 初入草原 | 圆圈小草 + π 符号 |
| L2 | 数字林道 | 圆圈小草 + ∑ 符号 |
| L3 | 公式丘陵 | 圆圈小草 + ∞ 符号 |
| L4 | 喘息营地 | 圆圈小草 + √ 符号（呼吸关） |
| L5 | 几何峡谷 | 圆圈小草 + x² 符号（Boss 关前奏） |
| L6 | 函数沼泽 | 圆圈小草 + ≠ ≈ 符号 |
| L7 | 数列峭壁 | 圆圈小草 + ± 符号 |
| L8 | 微风高地 | 圆圈小草 + + − 符号（呼吸关） |

> L5 是「数学草原」最后一关 + Boss「内卷怪·加班老登」的承载关。Boss 召唤时**不切换**主题，仍保持 `math`。

### 1.6 主题音效（待音效团队补充，不在本规格范围）

## 3. science（科学实验室，L15–L20）

## 4. final（终极：考神祭坛，L20 终极阶段）

### 4.1 主题氛围

> **关键词**：黑紫渐变，神秘符文，三学科混搭，「终极 Boss 的舞台」。
> **目标玩家**：15–18 岁通关者，第一印象应该是「史诗感、压倒感、终极感」。
> **色彩温度**：黑紫冷 → 深红暖渐变，传达「从理性到情绪」的 Boss 战氛围递进。

### 4.2 触发时机

| 条件 | 时机 |
|---|---|
| L20（元素火山）的 Boss「考神」**召唤时** | `MonsterSpawner.spawnBoss()` 调用瞬间 |
| 主题切换持续 | 持续到 Boss 被击杀 |
| Boss 击杀后 | 主题切回 `science`（保持 L20 默认主题） |

### 4.3 背景色与地面

| 项 | 值 | 说明 |
|---|---|---|
| **背景底色** | **渐变 `Palette.background.deep` `#0B1622` → `#2A0E2E`（自定义深紫）** | 上半深蓝、下半深紫，`Phaser.GameObjects.Graphics` 绘制渐变矩形 |
| **地面棋盘主色** | `#1A0824`（自定义深紫）+ `#2A0E2E` 交错 | 比 science 主题更紫更暗 |
| **地面网格线** | `Palette.text.hint` `#6F8BA3`，`alpha 0.4`，比 science 主题**亮 1 档**（强化终极感） | — |
| **地面棋盘对比度** | `≈ 1.20 : 1`（比前 3 主题略强，强化舞台感，但仍在光敏安全 1.5:1 以下） | — |

> ⚠️ **新增色值说明**：`#2A0E2E` 与 `#1A0824` 是**本次终极主题专用色**，**仅在 final 主题使用**，**不加入 `Palette.ts` 常量**（保持零色值膨胀原则）。工程侧在 `BossScene.ts`（T-024 新增）内**局部 const** 使用。

### 4.4 装饰规格

> **核心思路**：3 学科装饰全部保留 + 新增神秘符文 + 黑紫氛围光。
> **数量上限**：同屏 `30` 个装饰对象池（比普通主题多 10 个，承载终极氛围）。

| 装饰元素 | 形态 | 数量 | 位置分布 | 视觉 |
|---|---|---|---|---|
| **3 学科装饰（保留）** | math 圆圈小草 + english 椭圆树叶 + science 三角锥/试管，**随机混合** | 共 **20 个**（每学科约 7 个） | 战场区 4 边分布，避开玩家出生点 | 各自主题色，但**alpha 全部降到 0.4**（让位于终极氛围） |
| **神秘符文** | `Phaser.GameObjects.Text`，从 `['✦', '✧', '◈', '⬡', '✴', '✶', '✷', '✸']` 随机选 | **6 个** | 战场区 4 角各 1–2 个 | `FS_H2 40`，色 `#A040FF`（自定义深紫光），`alpha 0.6`，**逆时针缓慢旋转** `360° / 8000ms Linear` |
| **氛围光（中心环）** | 圆环 `radius 220`，描边 `3px #A040FF alpha 0.5`，**绕战场中心缓慢旋转** `360° / 12000ms Linear` | **1 个** | 战场中心 `(480, 320)` | 描边 + 旋转，传达「祭坛光环」 |
| **背景粒子（静态）** | 4 颗小圆 `radius 2`，填充 `#FFFFFF alpha 0.4`，分散在 `(100, 100)` `(860, 100)` `(100, 540)` `(860, 540)` 角落 | **4 个** | 4 角落 | 静态，无 tween（**终极主题不使用 ParticleEmitter**，与 MVP 性能红线一致） |

### 4.5 主题切换动效

| 步骤 | 视觉 | 时长 | 缓动 |
|---|---|---|---|
| 1 | 背景底色 `science` → `final` 渐变：上半 `alpha 1` 覆盖 `Palette.background.deep` 临时矩形，**从上方滑入** `y -640 → 0` | `400ms` | `Quad.easeIn` |
| 2 | 下半深紫渐变：另 1 个矩形从下方滑入 `y 640 → 0` | `400ms`，**与步骤 1 同步** | `Quad.easeIn` |
| 3 | 神秘符文 `alpha 0 → 0.6 / 600ms`，**错峰 100ms** | 单个 `600ms` | `Quad.easeOut` |
| 4 | 氛围光环 `alpha 0 → 0.5`，旋转从 0 开始 | `600ms` | `Cubic.easeOut` |
| 5 | 3 学科装饰**透明度全部降到 0.4**（一次性 setAlpha，不渐变） | 瞬时 | — |

**总切换时长 `≤ 800ms`**，期间 Boss 同步生成（不影响）。

### 4.6 主题恢复动效（Boss 击杀时）

| 步骤 | 视觉 | 时长 | 缓动 |
|---|---|---|---|
| 1 | 氛围光环 `alpha 0.5 → 0`，神秘符文 `alpha 0.6 → 0`，**同步** | `400ms` | `Quad.easeIn` |
| 2 | 背景渐变临时矩形 `alpha 1 → 0`，**反向** `y 0 → -640`（上矩形）与 `y 0 → 640`（下矩形），**同步** | `400ms` | `Quad.easeOut` |
| 3 | 3 学科装饰**透明度从 0.4 恢复到 science 默认值**（一次性 setAlpha） | 瞬时 | — |

**总恢复时长 `≤ 600ms`**。

## 8. 场景主题视觉约束清单（与 visual-spec-mvp.md 红线对齐）

| 红线 | 落实方式 |
|---|---|
| **零素材红线**（§1.4） | 所有场景装饰均由 `Phaser.GameObjects.Graphics` 程序化绘制后 `generateTexture()` 生成 |
| **性能红线**（GDD 1.2） | 装饰对象纯静态绘制（不参与碰撞/检测），对象池约束 `≤ 30`，不参与 tween 计数 |
| **不引入新色值（普通主题）** | math/english/science 主题全部沿用 `Palette.ts` 现有色值（`themeColor` / `accentColor` / `secondary` / `grassField`），**不创建新色常量** |
| **终极主题例外** | final 主题使用 `#2A0E2E` / `#1A0824` / `#A040FF` 3 个新色值，**仅在 `BossScene.ts`（T-024 新增）局部 const**，**不入 Palette.ts**，避免色值膨胀 |
| **不破坏答题公平**（§5） | 场景主题**仅在割草场景**（`GrassCuttingScene`）生效，答题场景始终保持 `BG_MAIN` `#16203A` 主题 |
| **不影响关卡过渡** | 场景主题**不参与关卡切换动效**（§4.12 遮罩动画），仅在 `GrassCuttingScene` 内显示 |
| **不引入 ParticleEmitter** | 终极主题的「角落粒子」是 4 颗静态 sprite，**不使用 ParticleEmitter**（与 MVP 性能红线一致） |
