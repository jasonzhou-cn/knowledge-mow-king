# Boss 视觉规格说明书（T-023，960 × 640）

> 作者：art-director ｜ 版本：v1.0 ｜ 适用：MVP 全部 5 个 Boss 关（L5 / L10 / L14 / L17 / L20）
> 设计分辨率：**960 × 640**（与 `src/main.ts` GAME_WIDTH/GAME_HEIGHT 一致，Scale.FIT）
> 复用色板：完全沿用 `src/ui/Palette.ts` 与 `design/art/visual-spec-mvp.md` §2.1 配色，**不再引入新色值**
> 风格基线：**沙雕恶搞**（学渣逆袭 / 内卷 / 躺平 / 考神梗 / 表情包），对应玩家 9–18 岁中国学生
> 零素材红线（`visual-spec-mvp.md` §1.4）：**所有 Boss 视觉元素均由 `Phaser.GameObjects.Graphics` 程序化绘制后 `generateTexture()` 生成**，不引用任何 png / jpg / 字体文件
> 工程定位：**纯规格文档**，不下载任何素材、不修改任何 .ts / .json 代码

## 0. 全局约定（5 个 Boss 共用）

### 0.1 Boss 体型基准

| 项 | 值 | 说明 |
|---|---|---|
| 基础 radius | **46** | 与 `public/config/grassCuttingConfig.json` 的 `bossSettings.radius: 46` 一致 |
| 基础显示尺寸 | **92 × 92** | `radius × 2`，对象池沿用 `MonsterSpawner.preallocate()` 的 `setDisplaySize(radius*2, radius*2)` |
| 与 MonsterSpawner 对齐 | **`Monster.radius = 46`、`isBoss = true`** | 不改 `MonsterSpawner` 的接口与字段，只新增 Boss 专属的「阶段/表情/技能表现」配套绘制 |
| 描边内缩 | **2px**（描边宽 `4`，半径需减 `lineWidth / 2 = 2`） | 与 `visual-spec-mvp.md` §0.4 描边内缩规则一致 |
| 描边色 | **一律 `BG_DEEP` `#0A1020`** | 与现有小怪描边同源；Boss 描边只起到「剪影感」作用，不干扰主色识别 |
| 主填充色（阶段 1） | 取自 `Palette.accent.gold` `#FFCC4D` | 与 `MonsterSpawner.refreshTint` 的 Boss 分支一致：`mixColor(GOLD, WRONG, 1 - ratio)` |
| 受击闪白 | **`setTintFill(0xFFFFFF)`，`70ms`** | 与 `visual-spec-mvp.md` §4.5 一致（实现侧 T-006 已统一 `70ms`） |
| 击退 | **免疫** | `MonsterSpawner.knockback()` 已对 `isBoss=true` 直接 return |
| 击杀飞散 | **禁用** | Boss 死亡走「Boss 专属收场」而非尸体飞散，详见各 Boss 的 `death` 表情 |
| 深度 `depth` | **`30`**（与普通小怪同层，不抢玩家/HUD 视线） | 与 `visual-spec-mvp.md` §0.2 一致 |
| 阶段切换 `tween` 时长 | **阶段 1→2：`400ms`；阶段 2→3：`400ms`** | Back.easeOut，`easeParams: [1.4]`；L20 阶段 3→4 同 |
| 阶段切换 `tween` 数量 | 每阶段切换 ≤ **3 个并发 tween**（缩放 + 描边色 + 配件透明度），远低于 `MAX_TWEENS 40` 上限 | 与 `visual-spec-mvp.md` §4.0 一致 |

### 0.2 Boss 阶段化总规则

| 阶段 | 触发条件 | hp 阈值（L5 / L10 / L14 / L17 / L20） | 共享视觉变化 |
|---|---|---|---|
| 阶段 1（入场） | Boss 生成瞬间 | `100%` | 默认表情 `idle_normal`；主填充色按 `MonsterSpawner.refreshTint` 的 Boss 配色 |
| 阶段 2（怒） | hp 首次跌破 `66.67%` | `< 2/3` | 表情切 `phase_2`；饱和度 +20%（HSL.S × 1.2）；轻微抖动（x/y ±2px 持续 80ms，2 次） |
| 阶段 3（狂暴） | hp 首次跌破 `33.33%` | `< 1/3` | 表情切 `phase_2` 加强版；**新增配件**（各 Boss 不同，见 §1.5–1.9）；抖动加强到 ±4px |
| 阶段 4（仅 L20 考神专属） | hp 首次跌破 `16.67%` | `< 1/6` | 表情切 `phase_2` 最强版；Boss 本体 `alpha 1.0 → 0.85`（半透明残影感）；新增配件 2 套 |
| 死亡 | hp 归零 | `0%` | 表情切 `death` 持续 1s；之后整体 `scale 1.0 → 0` + `alpha → 0`，共 `600ms`，Back.easeIn |

> **阶段切换不间断技能释放**：阶段 2/3/4 切换的瞬间**不打断**正在进行的技能动画，只对 Boss 本体（缩放/抖动/饱和度/配件）做过渡，避免技能半截被截断的观感。

### 0.3 沙雕表情规则（5 套表情，与 5 个 Boss 通用）

> 所有表情**全部用 Phaser 程序化绘制**（不依赖 emoji/字体），均由「眼睛 + 嘴」两组 `Graphics` 组成。
> 表情切换 = 销毁旧的 `Graphics` + 重绘新的 `Graphics`，不修改底层的 `radius` / 填充色。

| 表情名 | 视觉描述 | 触发条件 | 切换时长 | 通用参数 |
|---|---|---|---|---|
| `idle_normal` | 圆脸 + **正常黑眼**（直径 `8` 实心圆）+ **微笑嘴**（弧线，宽 `20` 高 `6`，弧度 `0.4`） | 默认 / 受击后恢复 | `120ms` `Linear` | 眼睛色 `BG_DEEP` `#0A1020`；嘴色 `BG_DEEP` `#0A1020` |
| `attacking` | **皱眉**（眉头一条短粗横线，宽 `18` 倾斜 `±12°`）+ **张嘴吼**（张开的椭圆，宽 `16` 高 `14`，填充 `#0A1020`，描边 `2` 同色） | 技能释放瞬间 `200ms` 后恢复 | `80ms` 瞬时切换 | 眉头线宽 `4`；张嘴椭圆描边让吼的嘴型更明显 |
| `hurt` | **眼冒星星**（左眼 3 颗小四角星，每颗边长 `4`，右眼 1 颗稍大边长 `6`）+ **嘴歪斜**（嘴倾斜 `-15°`，弧度保持 `0.4`） | 受到 `1/10 maxHp` 伤害（即 hp 跌破 10% 步进时） | `120ms` `Quad.easeOut` | 星形用 `Phaser.GameObjects.Graphics` 的 4 点 polygon 画，alpha `0.85` |
| `phase_2` | **凶光眼**（眼睛由圆形改为「> <」斜四边形，高 `10` 宽 `14`，边缘 `1px` 红线 `#FF5A5A`，填充黑）+ **龅牙**（嘴张开露出上下 4 颗方牙，每颗 `4×4`，白 `#F5F8FF`） | 进入阶段 2 / 3 / 4 | `200ms` `Back.easeOut [1.4]` | 凶光眼 alpha `0.9`；龅牙与嘴之间留 `2px` 缝，区分上下牙 |
| `death` | **翻白眼**（眼睛外圈白 `#F5F8FF` 直径 `10`，内点黑 `#0A1020` 直径 `3`，偏移到眼球上沿）+ **嘴流口水**（嘴角挂一条白线 `#F5F8FF`，宽 `2`，长 `10`，alpha `0.8`，用 `tween` 让其上下抖动 `±2px / 200ms` 持续 `1s`） | hp 归零瞬间持续 `1s` | `400ms` `Quad.easeIn` | 翻白眼只在死亡后 `1s` 内；之后随 Boss 整体缩放淡出 |

**表情位置基准**（相对 Boss 中心 `0,0`，5 个 Boss 共用）：

| 元素 | 相对坐标 (x, y) | 尺寸 |
|---|---|---|
| 左眼中心 | `(-12, -10)` | 直径 `8` |
| 右眼中心 | `(+12, -10)` | 直径 `8` |
| 嘴中心 | `(0, +14)` | 宽 `20` 高 `6` |

### 0.4 配件挂载点（5 个 Boss 共用）

> 所有「阶段 2/3/4 新增配件」均通过「相对 Boss 中心的 offset」挂载在 Boss 本体上。
> 配件的 `depth` = `30.5`（Boss 本体之上 / 普通小怪之上，避免被同屏小怪遮挡但又不抢玩家视线）。

| 配件名（通用槽位） | 相对坐标 (x, y) | 备注 |
|---|---|---|
| `head_top` | `(0, -46)` | 头顶正上方（帽 / 头饰用） |
| `face_center` | `(0, 0)` | 脸部中央（眼镜 / 工牌 / 面具用） |
| `left_shoulder` | `(-30, +20)` | 左肩（肩章 / 翅膀 / 火焰起点） |
| `right_shoulder` | `(+30, +20)` | 右肩 |
| `back` | `(0, 0)` | Boss 本体背后（火焰 / 烟雾 / 残影用，相对坐标系下绘制在 `radius - 6` 内层） |
| `skill_origin` | `(0, 0)` | 技能生成点（KPI 牌 / 元素小怪等从这里飞出） |

### 0.5 通用血条规格（5 个 Boss 共用）

> 与 `MonsterSpawner` 的 `bossHpRatio` 接口对齐：HUD 顶部显示 Boss 血条，普通关不显示。

| 项 | 值 | 说明 |
|---|---|---|
| 容器尺寸 | `640 × 16`（960 × 640 占比 2/3，足够醒目） | 与 `visual-spec-mvp.md` §3.2 进度条尺寸一致 |
| 容器位置 | 顶部居中 `(480, 56)`，x `160`–`800`，y `48`–`64` | 留出 HUD（`0–72`）与 Boss 血条 `8px` 间距 |
| 槽底色 | `Palette.combat.hpBarBg` `#2A1A1F` | 沿用 `Palette.ts` |
| 填充色 | `Palette.combat.monsterHpFill` `#D94F4F` | 沿用 |
| 描边 | 无（圆角 `8`，与进度条同语言） | 与 `visual-spec-mvp.md` §3.2 进度条圆角一致 |
| 阶段切换视觉提示 | 阶段 2 时填充色微调向 `#FF7A59`；阶段 3 时填充色切 `#FF5A5A` | 颜色渐变 `300ms` `Linear`，**不是**断崖式变色 |

| 数字血量 | 不显示数字，仅靠填充条长度传达 | 简洁原则；玩家关心的是比例不是绝对值 |

> - 阶段 3：「今晚的 OKR 还有一半没对齐！」

#### 1.1.1 Base 体型

| 项 | 值 |
|---|---|
| 主形 | **正方形**（边长 92×92，圆角 `12`，区别于普通小怪的圆形/三角/六边形，传达「格子间工位」意象） |
| 主填充色 | `Palette.accent.gold` `#FFCC4D` |
| 描边 | `#0A1020`，`4px` |
| 半径（碰撞） | `46` |
| 描述符代码 | `BOSSSHAPE_SQUARE` |

#### 1.1.2 默认配件（阶段 1 就有，阶段 2/3 加重）

| 配件 | 位置 | 视觉 | 说明 |
|---|---|---|---|
| **西装领带** | `face_center` 下方 `(0, +18)` 到 `(0, +38)` | 两条等腰三角（领），宽 `10` 高 `8`；一条矩形（领带），宽 `6` 高 `16`；领色 `#1B3550`，领带色 `#FF5A5A` | 三角/矩形组合，纯描边 + 填充 |

#### 1.1.3 阶段切换视觉变化

| 阶段 | 变化 |
|---|---|

#### 1.1.4 技能视觉表现（阶段 1 = 「扔 KPI 牌」，阶段 2 = 「扔 OKR 牌」，阶段 3 = 「扔 PPT 牌 + 火焰尾迹」）

| 步骤 | 视觉 | 时长 | 缓动 |
|---|---|---|---|
| 1 | Boss 表情切 `attacking`（皱眉 + 张嘴吼） | `80ms` 瞬时 | — |
| 2 | 从 `skill_origin` 生成 1 个「牌子」精灵（圆角矩形 `32 × 20`，描边 `2 #0A1020`，填充 `#F5F8FF`，中央黑色文字 `KPI/OKR/PPT`，`FS_BODY 28`） | — | — |
| 3 | 牌子朝玩家位置**旋转飞出**：起点 Boss 中心 `(480, 320)`（默认出生点，阶段 3 时改为 Boss 当前位置），终点玩家位置；**绕自身中心旋转 `360° / 600ms`**，整体沿抛物线弧线前进 | `600ms` | `Cubic.easeIn` |

| 5 | Boss 表情恢复 `idle_normal`（阶段 3 保持 `phase_2`） | `120ms` `Linear` | — |

**每 3.0s 释放一次**（来自 `BossSettings` 的技能计时，工程侧在 `BossSystem` 加 `skillCooldown` 字段，T-024 范围；本规格仅定视觉）。

> 阶段 3 火焰尾迹：牌子背后拖一条 `4px` 宽、`alpha 0.6` 的橙红渐变线（`#FF9F45 → #FF5A5A`），长 `40px`，与牌子同向运动。

### 1.3 L14 · 完形克星·语法之王（英语密林，hp 2600）

> **Boss 立意**：英语完形填空的拟人化。戴博士帽 + 试管眼镜（学霸梗），用「错题弹幕」攻击。
> **关联台词**（取自 `bossDialogue.json`）：
> - 入场：「Grammar is my weapon. Let the test begin.」
> - 阶段 1：「Which answer fits best?」
> - 阶段 2：「语法无懈可击！」
> - 阶段 3：「主谓宾定状补，一个都不能少！」

| **不破坏答题公平红线**（§5） | Boss 视觉**完全在割草场景**（`GrassCuttingScene`）出现，**不进答题场景**（`QuestionScene`）；Boss 头像不进答题卡、判分逻辑不读取 Boss 状态 |
| **不放大 Boss 碰撞半径** | 维持 `radius = 46` 与现有 `Monster.radius` 字段一致；不通过放大碰撞来「显得更吓人」，避免玩家无解 |
| **不遮挡玩家视线** | Boss 配件 `depth = 30.5`，不抢 HUD（`70`）/ 玩家（`40`）/ 攻击范围环（`40`）；血条 `depth = 70` 与 HUD 同层，常驻顶部，不抢小怪层 |
